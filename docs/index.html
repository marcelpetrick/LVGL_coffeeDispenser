LVGL Coffee Dispenser HMI

Documentation

A desktop-first LVGL prototype of a touch coffee-dispenser HMI: LVGL 9.6 and SDL2 on Linux, with the controller and beverage model kept display-independent and unit-tested. These are the pages published from the repository’s docs/ folder.

Measurements

  • Did LVGL 9.6 get faster? Eight paired runs of LVGL 9.3.0 against 9.6.0 on the same 800×480 HMI: render time, frame budget, memory, and what the measurement does not cover.

Engineering notes

  • Architecture Layering rules: the UI requests state changes through the controller, and only the controller talks to the dispenser service.
  • UI flow The screens and the transitions between them.
  • Build and deploy Build paths, the quality gate, generated report locations, packaging, and the measurement scripts.
